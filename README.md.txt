Grepolis - Exportar Tropas

Userscript para Grepolis que permite exportar os dados de tropas das cidades para CSV ou para um ficheiro compatível com Excel.

Versão

1.12.1

Requisitos

Grepolis aberto num navegador compatível com Tampermonkey.

Conselheiro Curador ativo no jogo.

Instalação

Instalar o Tampermonkey no navegador.

Abrir o ficheiro Grepolis-Exportar-Tropas-V1.12.1.user.js a partir do GitHub.

Copiar o conteúdo para um novo script no Tampermonkey ou instalar a partir do endereço Raw, caso esteja disponível.

Privacidade e segurança

O script não carrega bibliotecas JavaScript de domínios externos.

O script não envia intencionalmente dados do jogo para servidores externos.

A recolha, preparação e exportação dos dados são efetuadas localmente no navegador.

A exportação é bloqueada quando o jogo não confirma que o Curador está ativo.

O script utiliza @grant none e não solicita a permissão unsafeWindow.

Formatos de exportação

CSV (.csv)

Tabela HTML compatível com Excel (.xls); não é um ficheiro .xlsx nativo.

Aviso

Este é um projeto não oficial, criado por um jogador. Não é afiliado à InnoGames nem ao Grepolis. A compatibilidade e a aprovação dependem das regras e da revisão do suporte do jogo.
